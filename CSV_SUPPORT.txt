📋 HOW TO USE WITH CSV:

1️⃣  Save your Excel file as CSV:
   • Open "Post Tracker.xlsx" in Excel
   • File → Save As
   • Choose "CSV UTF-8 (Comma delimited) (*.csv)"
   • Save as "Post Tracker.csv"

2️⃣  Run the scraper (same as before!):
   • Double-click "RUN_SCRAPER.bat"
   
3️⃣  The scraper automatically detects your file:
   ✓ Found "Post Tracker.csv"? → Uses CSV
   ✓ Found "Post Tracker.xlsx"? → Uses Excel
   
4️⃣  Results are saved in the SAME format:
   • CSV input → CSV output
   • Excel input → Excel output

📊 EXAMPLE WITH YOUR CSV:

Your CSV file should look like:
┌─────────────────────────────────────────┐
│ https://x.com/user/status/123...        │
│ https://x.com/user/status/456...        │
│ https://x.com/user/status/789...        │
└─────────────────────────────────────────┘

After scraping, it becomes:
┌──────────────────────────┬──────────┬─────────┬───────┐
│ URL                      │ Username │ Text    │ Likes │
├──────────────────────────┼──────────┼─────────┼───────┤
│ https://x.com/user/12... │ @user    │ Tweet 1 │ 1.5K  │
│ https://x.com/user/45... │ @user2   │ Tweet 2 │ 892   │
│ https://x.com/user/78... │ @user3   │ Tweet 3 │ 2.1K  │
└──────────────────────────┴──────────┴─────────┴───────┘

💡 TIPS FOR CSV FILES:

✅ GOOD CSV FORMAT:
   • First column has Twitter/X links
   • UTF-8 encoding (recommended)
   • Comma-delimited
   • Headers in first row (optional)

⚠️ THINGS TO CHECK:
   • File name is exactly: "Post Tracker.csv"
   • Links are in the first column
   • File is in the same folder as the scripts
   • No special characters causing issues

🎯 WHICH FORMAT IS BETTER?

CSV:
✅ Faster to load
✅ Smaller file size
✅ Works with more programs
✅ Easier to edit in text editor

Excel:
✅ Better formatting options
✅ Can have multiple sheets
✅ Better for complex data

For web scraping → CSV is usually FASTER and easier!
