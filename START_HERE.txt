╚══════════════════════════════════════════════════════════════════════╝

When you run the scraper, you can choose:

   [1] Test Mode        → First 3 tweets   (~15 seconds)
   [2] Small Batch      → First 20 tweets  (~2 minutes)

   [5] Custom Range     → You choose       (you specify)

╔══════════════════════════════════════════════════════════════════════╗
║                      TROUBLESHOOTING                                 ║
╚══════════════════════════════════════════════════════════════════════╝

❌ "Chrome not found"
   → Install Google Chrome browser

❌ "Module not found"  
   → Run: pip install selenium webdriver-manager

❌ "Excel file not found"
   → Make sure "Post Tracker.xlsx" is in the same folder

❌ Scraper not getting data
   → Try logging into Twitter when the browser opens
   → Some tweets may be deleted or private

❌ Getting blocked
   → Don't scrape too fast (delays are built-in)
   → Process in smaller batches
